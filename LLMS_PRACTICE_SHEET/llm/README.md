# Day 15 - LLM Fundamentals

## Objective

The objective of this project is to understand the fundamentals of Large Language Models (LLMs), interact with different LLM providers, experiment with prompt engineering, build a simple chatbot, and analyze API token usage.

---

## Tasks Completed

### Task 1 - Multi-LLM Comparison

Compared responses from:

- Google Gemini
- Groq (Llama)

Prompt used:

"Explain Machine Learning in simple words."

Observations:

- Gemini provided detailed explanations.
- Groq generated concise and structured responses.
- Different LLMs produce different styles of outputs.

---

### Task 2 - Prompt Engineering Experiments

Tested multiple prompt styles:

- Simple Prompt
- Detailed Prompt
- Role-based Prompt

Goal:

Understand how prompt design affects response quality.

Observation:

More specific prompts generated better and more relevant responses.

---

### Task 3 - AI Chatbot using Groq API

Built a simple chatbot that:

- Accepts user input
- Sends prompts to Groq API
- Returns AI-generated responses

Technologies:

- Python
- Groq API
- dotenv

---

### Task 4 - Token Usage Analysis

Tracked:

- Prompt Tokens
- Completion Tokens
- Total Tokens

Generated:

- CSV usage logs
- Token usage visualization

Purpose:

Understand API usage and potential costs.
