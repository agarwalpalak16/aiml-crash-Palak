# Project Report - Day 15 LLM Fundamentals

## Introduction

Large Language Models (LLMs) have become one of the most important technologies in Artificial Intelligence. This project focuses on understanding how LLMs work, comparing different providers, experimenting with prompt engineering, building a chatbot, and analyzing token usage.

---

## Task 1: Multi-LLM Comparison

### Objective

Compare outputs generated by different LLM providers.

### Models Used

- Google Gemini
- Groq Llama

### Prompt

Explain Machine Learning in simple words.

### Observation

Both models successfully answered the prompt but differed in:

- Response style
- Level of detail
- Structure

### Conclusion

Different LLMs have unique strengths and response patterns.

---

## Task 2: Prompt Engineering Experiments

### Objective

Study how prompt design affects model responses.

### Prompt Types

1. Simple Prompt
2. Detailed Prompt
3. Role-Based Prompt

### Observation

Role-based and detailed prompts produced more accurate and useful outputs.

### Conclusion

Prompt engineering significantly improves response quality.

## Task 4: Token Usage Analysis

### Objective

Measure API token consumption.
